# Working manuscript

`1_Nature.tex` is the latest supplied carbon-study manuscript. The companion cover letter, bibliography, journal style and figure assets are included. All figure dependencies referenced in the source are present.

Build from this directory with a LaTeX installation supporting the Springer Nature class, for example `latexmk -pdf 1_Nature.tex`. The original complete supplied folder, including supplementary analysis metadata, is preserved separately as `manuscript-source.tar.gz` in the research release.

The `Nature_Energy/` folder in the research archive contains earlier reference-cohort manuscript sources and evidence. Use this working manuscript for continued writing. Portable analysis code is in `analysis/carbon/` at the repository root.

# Reconstruct the carbon-study figures

These builders read completed evidence; they do not call a model, optimizer or power-flow engine. Install `../requirements.txt` from this directory (or `analysis/requirements.txt` from the repository root).

Extract all research release archives into the same external directory. `PACKAGE_ORIGIN.json` records original absolute prefixes, which these builders map to the extracted root without changing the original evidence. Additional mappings can be supplied as a JSON object in `GRID_AGENT_ARCHIVE_MAP`.

```bash
export GRID_AGENT_CARBON_ANALYSIS=/path/to/rebuilt-carbon
python -B analysis/carbon/build_carbon_figures.py \
  --project /path/to/research-archive --out "$GRID_AGENT_CARBON_ANALYSIS"
python -B analysis/carbon/geo_carbon.py \
  --project /path/to/research-archive --out "$GRID_AGENT_CARBON_ANALYSIS"
python -B analysis/carbon/build_combined_grid_carbon.py \
  --project /path/to/research-archive --out "$GRID_AGENT_CARBON_ANALYSIS"
python -B analysis/carbon/build_carbon_expert_comparison.py \
  --project /path/to/research-archive --out "$GRID_AGENT_CARBON_ANALYSIS"
```

The sequence rebuilds `carbon_data.json`, all forty cost/emission outcomes and selected portfolios, geographic evidence/atlas, paired investment/emissions maps, then expert-plan comparisons. Existing archived `figure_carbon/` outputs are available for comparison. The original Figure 1 is retained in the archive; the alternative carbon framework generated by the first builder is an unused draft.

The map builders require the preserved Natural Earth archives under `Nature_Energy/evidence/geographic_20261003/`. They import the release's drawing code. The paired emissions map verifies accepted dispatch hashes and reconciles 8,760-hour zonal emissions. The scripts retain study-specific assertions, including the archived winners; they are not a generic plotting interface for arbitrary new campaigns.

The `--out` directory is separate from the source archive. All saved costs, capacities, emissions and selection rules are retained; portability changes only source imports and archive/output path resolution. Output audit hashes can differ after relocation, while unchanged original artifacts retain their archived hashes.

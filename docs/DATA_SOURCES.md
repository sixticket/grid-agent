# Data sources and study vintages

This is a code-only release. It does not include regional time series, input packs, raw reports, workbooks, geographic data, weather responses, or experiment outputs. Obtain the required inputs independently and retain their source terms and attribution. The code license does not license third-party data.

The descriptions and URLs below were transcribed from the study's saved source catalogues, input provenance, preprocessing code, and manuscript bibliography through 8 October 2026. They identify the sources actually used; they are not a claim that every URL is currently available or that its current contents match the archived copy. A publisher landing page or citation alone is insufficient to reconstruct the exact study inputs. [INPUT_DATA.md](INPUT_DATA.md) describes the runtime schema and missing preprocessing dependencies.

## Scope

The current paper reports 96 trajectories: eight systems × three matching demand/resource-weather years × GPT-6.1 Sol/Opus × single/multi. The 2023 resource condition uses ERA5. The 2030/2035 cases use MPI-ESM1-2-HR / r1i1p1f1 / SSP2-4.5 NASA NEX-GDDP-CMIP6 v2.0 daily projections, synthetically reconstructed using ERA5 intraday templates. Every profile retains the 8,760-hour 2023 model clock. Regional annual demand outlooks scale the inherited 2023 demand shape before NASA resources are attached. Existing fleet and cost/policy assumptions remain inherited; new-build costs use the recorded 2030 technology-cost basis. Demand-only intermediates retaining ERA5 resources are excluded from the active future reporting cohort.

## NASA future resources

- [NASA NEX-GDDP-CMIP6 dataset](https://doi.org/10.7917/OFSG3345), [v2 technical note](https://www.nccs.nasa.gov/wp-content/uploads/2025/06/NEX-GDDP-CMIP6-v2-Tech_Note.pdf), and [Thrasher et al. 2022](https://doi.org/10.1038/s41597-022-01393-4). The paper uses MPI-ESM1-2-HR / r1i1p1f1 / SSP2-4.5 for 2030/2035, with target-year boundary days. Archive query, selected grid, units, calendar and response hashes.
- Daily tasmin/tasmax constrain temperature extrema; rsds constrains daily radiation energy; sfcWind sets the ERA5 wind multiplier. ERA5 2023 intraday shapes create synthetic hourly fields. New ERA5 companion data supply 10m wind and boundary hours. The final annual model clock remains 2023.
- [NASA source and reconstruction code](../preprocessing/nasa_climate/README.md) preserves conservation checks and wind flags. The paper uses 16 packs/116 annual node profiles. Three-GCM preprocessing remains an optional 48-pack/348-profile sensitivity configuration.

## Shared weather, technology, and cost sources

- [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), selecting ERA5: one point per representative node, 2023 weather with boundary padding. Required hourly fields are temperature at 2 m, wind speed at 100 m, shortwave radiation, direct normal irradiance, and diffuse radiation. Archive the exact query, coordinates, timezone conversion, response bytes, and SHA-256. Radiation is shifted from its preceding-hour mean to the load interval; PV is evaluated at the interval midpoint.
- [SAM/PVWatts](https://sam.nrel.gov/photovoltaic/pvwatts.html), study preprocessing with PySAM 7.1.1 / `Pvwattsv8`: 1 MW DC, DC/AC ratio 1, fixed rack, tilt equal to absolute latitude, equator-facing, 14% losses. Save all exported system parameters. The 100-m wind series serves as a thermal-wind proxy.
- [2020 ATB NREL Reference 4-MW, 150-m turbine](https://natlabrockies.github.io/turbine-models/2020ATB_NREL_Reference_4MW_150.html), tabular curve from [turbine-models](https://github.com/NatLabRockies/turbine-models). The study interpolates against ERA5 100-m wind without additional wake, terrain, or hub-height corrections.
- [2024 Electricity ATB data](https://atb.nlr.gov/electricity/2024/data), archived version 4: Market / Moderate / 2030, 30-year recovery basis for the main US-derived new-build costs. The non-South-African packs use the prepared `costs_us.json` scenario basis; this is not a country-specific project quotation.
- [PyPSA technology-data](https://github.com/PyPSA/technology-data), archived 2030 CSV: South African costs and the hydrogen chain. South African discount rate 10% and EUR-to-USD conversion 1.08 are study assumptions; hydrogen costs in the US-derived basis retain the declared 7% basis. The archived source hash and prepared per-value derivation are needed because the repository URL alone does not pin a revision.

## Reproduction boundary

Exact study reproduction requires the same source bytes, extraction coordinates, spatial mappings, prepared costs, temporal transformations, numerical environment, and case-specific runtime profile. The published South African source does not distribute the original regional Eskom transformer observations used to calibrate the demand model. Supply-area boundaries and plant allocations also retain explicit uncertainty. Redownloading a mutable current fleet register or an updated weather response and rerunning a builder can produce a different scenario even when the citation is unchanged.

The study's final demand audit checked 319 input hashes and 135 source-file hashes and confirmed that single/multi inputs match. Those checks describe the private archived evidence, not an assertion that the excluded files are present in this code release. Keep a new manifest for independently reconstructed inputs and identify deviations from the study.

## Source-definition corrections retained in the current manuscript

AEMO baseline inputs use five-minute `TOTALDEMAND` averaged hourly, rather than the separately defined operational-demand series. Published STEP-wide 3,500-MW effects allocated to an ERCOT candidate are study modelling assumptions; generic NYISO ratings and New Zealand upgrade allocations also retain their explicit assumptions. PV output uses PVWatts v8, documented by its [model documentation](https://developer.nlr.gov/docs/solar/pvwatts/v8/) and [PySAM module](https://nrel-pysam.readthedocs.io/en/v7.1.0/modules/Pvwattsv8.html). Preserve source-vs-model distinctions when reconstructing inputs.
